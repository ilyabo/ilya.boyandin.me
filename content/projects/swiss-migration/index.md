I created this flow map at Interactive Things for Neue Zürcher Zeitung’s [2013 Swiss Maps summer series](/p/swiss-maps). It shows where people moved between cantons in 2011.

Wider arrows represent more moves, and circle sizes show each canton’s population. The bar chart compares total moves into and out of each canton.
