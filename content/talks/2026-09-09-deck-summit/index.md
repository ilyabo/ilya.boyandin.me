Talk description:

> SQLRooms is a local-first analytics workspace built around DuckDB, React, and AI-assisted exploration. It turns a DuckDB file into a portable data application where datasets, visualizations, dashboards, maps, and sandboxed apps can live together. This session explores how humans and AI agents can collaborate transparently to create malleable, shareable analytics tools beyond traditional notebooks and dashboards.
